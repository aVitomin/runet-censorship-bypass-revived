# 1.0.2 — обновление источников и интерфейса

**Готовится к выпуску.** Версия 1.0.2 ещё не опубликована.
Доступная версия и ссылки на магазины — в [инструкции по установке](../../user/INSTALLATION.md).

## Изменения

- **Antifilter** — дополнительный источник списка сайтов для Chromium и Firefox.
  Для подключения нужен отдельно настроенный прокси, Tor, Tor Browser или WARP
  и явное разрешение пользователя. Сам список не предоставляет прокси-сервис.
- Обновление базы из панели расширения. Дата исходных данных и последняя
  успешная проверка показаны отдельно; старые или неизвестные данные отмечены
  предупреждением.
- Обновление сохраняет действующие настройки, не применяет ожидающие изменения
  и не включает выключенную маршрутизацию.
- Исправлено расположение элементов настроек на узких экранах.
- «Ресурсы сайта»: ручной сбор дополнительных доменов одной обычной вкладки.
  Выбранные точные домены можно сохранить в правила «Прокси»; применение
  остаётся отдельным действием. Правила действуют для всего браузера.
- Обновлены зависимости инструментов разработки для устранения найденных
  уязвимостей. Рабочие зависимости расширения не изменены.

## Совместимость

Заявленные минимумы остаются **Chromium 108** и **Firefox 140** на настольных
системах с необходимыми API расширений. Это не подтверждение проверки каждой
версии или каждого браузера на этих движках. Основания и фактические проверки —
в [матрице совместимости](../BROWSER_COMPATIBILITY.md).

## English

- Antifilter is an optional website-list source for Chromium and Firefox.
  It requires a separately configured proxy, Tor, Tor Browser or WARP and
  explicit consent; the list itself does not provide a proxy service.
- Check routing-data updates from the popup. Source date and last successful
  check are separate; old or unknown data carries a warning.
- Updates retain applied settings, leave pending edits unapplied and keep
  routing off when it was off.
- Improved the Options layout on narrow screens.
- Website resources: manually capture additional hosts from one non-private
  tab and save selected exact hosts as browser-wide Proxy rules. Applying
  them remains a separate action.
- Updated development dependencies to address reported vulnerabilities;
  extension runtime dependencies are unchanged.
