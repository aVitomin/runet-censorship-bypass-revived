# Выпуск 1.0.2

3 ноября 2026 опубликован [Chromium ZIP 1.0.2](https://github.com/aVitomin/runet-censorship-bypass-revived/releases/tag/v1.0.2).
Firefox 1.0.2 опубликован в Mozilla Add-ons; подписанный XPI и checksum добавлены
в этот выпуск. Chrome 1.0.2 отправлен на проверку; публичная версия пока 1.0.1.

## Изменения

Antifilter для обоих браузеров, обновление базы из панели, отдельные даты данных
и проверки, ручной инструмент «Ресурсы сайта» и исправления узкого интерфейса.
Обновление сохраняет Effective, отложенные Saved и OFF. Новых разрешений нет.
[Руководство](../../user/USER_GUIDE_1_0_2.md) · [Приватность](../../release/PRIVACY_1_0.md).

## Пакет и проверки

- Исходники: `f7ae7756411212465bbcdff7ac7d2f3b3288fdcc`.
- [Trusted-main CI](https://github.com/aVitomin/runet-censorship-bypass-revived/actions/runs/41629228478): все обязательные проверки успешны.
- ZIP: `runet-censorship-bypass-mv3-1.0.2-f7ae775.zip`, 1348099 байт.
- SHA-256: `9c04b868cb1d739b38af0f595bc0c487f2183cd63b4ab6256d682279129e257c`. Публичный файл повторно скачан и побайтово проверен.
- Локальный общий gate: 1203 теста, lint, обе сборки. После настройки бюджета
  группы с базой 1,5 млн доменов отдельно прошёл Firefox gate: 580 тестов.
  Проверки и размер данных не ослаблялись; runtime-файлы не менялись.
- Канонические архивы содержат 92 файла Chromium и 91 Firefox; runtime совпал
  с локальным кандидатом. Все 382 файла reviewer source совпали с коммитом.
- Chromium 156.0.8078.79: распакованное обновление 1.0.1 → 1.0.2, OFF/активное
  состояние, отложенные настройки, Save/Apply и перезапуск. Автоматизация
  повторно подключала пакет; это не магазинное автообновление.
- Firefox 159.0: подписанный постоянный 1.0.1 → временный неподписанный 1.0.2,
  сохранение OFF/активности и настроек. На Windows Firefox 153.5.1 ESR —
  ограниченный сценарий обновления с активными и отложенными настройками.
- На Windows Firefox 159.0 проверены постоянное подписанное обновление 1.0.1 →
  1.0.2 и перезапуск без переустановки: подпись обязательна, OFF/Effective/ожидающие
  Saved сохранены. Это установка подписанного файла, не магазинная автодоставка.
  Linux, все минимальные версии и разрешённое Chrome-инкогнито не
  объявлены проверенными. Android не поддерживается; локальный XPI прошёл
  Mozilla addons-linter без ошибок, с одним предупреждением об Android.

Неподписанный Firefox XPI не предлагается как обычная пользовательская установка.
[Доступные способы установки](../../user/INSTALLATION.md).
