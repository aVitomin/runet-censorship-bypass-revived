# Release 1.0.3

Published on November 7, 2026: [Chromium ZIP and checksum](https://github.com/aVitomin/runet-censorship-bypass-revived/releases/tag/v1.0.3).
Later the same day, Firefox Add-ons published **1.0.3**, and its verified signed
XPI/checksum were added to the existing release. Chrome Web Store publication
of **1.0.3** was independently confirmed on **November 8, 2026, at 12:30 UTC**;
both stores now offer this version. The signed Firefox file remains **5221829**.
Public checksum sidecars were removed on November 8; SHA-256 values remain in
the release notes. Installable bytes, download URLs and the tag are unchanged.
See the [installation guide](../../user/INSTALLATION.md).

## Changes

- Less Chromium background work for configurations without usable proxy credentials.
- Coalesced overlapping Firefox site-status checks without caching completed results.
- Localized Chromium proxy sign-in safety-lock guidance.
- Collection of unused PAC/dataset bodies while preserving Saved, Effective,
  request-bound and recovery references; Firefox retains historical hashes separately.
- Simplified English contributor and engineering guidance.

No dependency selections, permissions, extension IDs, minimum versions or external
sources changed. Save remains separate from Apply. The measured improvements do
not establish that every symptom in [issue #115](https://github.com/aVitomin/runet-censorship-bypass-revived/issues/115)
is resolved. See [user changes](../../user/CHANGES_1_0_3.md) and
[implementation details](../release-drafts/1.0.3.md).

## Validation and limits

- Local integrated gate: 1,217 tests, lint and both package checks passed.
  Source/archive comparison covers 386 reviewer-source files, 92 Chromium files
  and 91 Firefox files. Unchanged implementation evidence was reused; it was not
  counted as a new run.
- Project dependency audits reported no known advisories; 283 registry signatures
  and 29 attestations were verified. No dependency upgrade was included.
- Windows Chrome 156.0.8078.80: routing, real proxy authentication, restart and
  ownership smoke; unpacked 1.0.2 → 1.0.3 update preserved OFF, Effective, pending
  Saved and installation identity across restart.
- Windows Firefox 159.0: signed 1.0.2 → temporary unsigned 1.0.3 preserved OFF,
  Effective and pending Saved. The candidate was reinstalled after restart;
  that pre-signing check did not establish permanent signed update/restart.
- After signing, Windows Firefox **159.0.1** accepted permanent signed 1.0.2 →
  1.0.3 with signature enforcement. OFF, Effective and pending Saved survived
  restart without reinstall in disposable profiles. This does not assert
  automatic store-delivery timing.
- Mozilla validation: zero errors and the existing Android minimum warning.
  Android is unsupported. The external validator was used only for the fixed
  controlled offline scan; this is not a claim about its own dependency security.
- Native IndexedDB abort/retry and schema upgrade were exercised. Physical disk
  exhaustion was not. Cleanup bounds large unused bodies, not total browser
  storage or the compact Firefox hash-history count.
- Linux, every minimum browser/derivative and automatic store delivery are not
  claimed as tested. Browser auth caches and established connections may outlive Apply.

## Signed Firefox payload

Mozilla file **5221829** is public. Its advertised hash matches the downloaded
XPI; all 91 runtime files match the canonical build. Only manifest formatting
(identical parsed JSON) and five Mozilla signature metadata files differ. Firefox
reports a valid signature during permanent installation and restart. Public
GitHub XPI/checksum bytes were downloaded again and matched exactly; the release
tag and existing Chromium assets are unchanged.

The remaining Chrome channel is tracked in the [store checklist](../../release/STORE_PUBLICATION_CHECKLIST.md).

## Release download presentation — November 8

Separate checksum assets were removed to keep downloads focused on the Chromium
ZIP and signed Firefox XPI. Exact SHA-256 values remain in the release notes,
README and installation guide. Package bytes, asset IDs and source tag are unchanged.
