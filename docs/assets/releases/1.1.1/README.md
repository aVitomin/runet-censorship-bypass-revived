### Capture details

Captured on Windows from the verified 1.1.1 runtime in Chrome 158.0.8127.37 and
Firefox 159.0.1, using disposable profiles and local example sites. Each image
is a 1280 × 800 RGB PNG. The site-panel image combines the native popup
capture with a localized caption. See the [release and checksums](https://github.com/aVitomin/runet-censorship-bypass-revived/releases/tag/v1.1.1)
and [browser compatibility notes](../../../development/BROWSER_COMPATIBILITY.md).
