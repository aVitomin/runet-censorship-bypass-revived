# Руководство 1.0.2

**Chromium 1.0.2 доступен как ZIP для ручной установки.**
Firefox 1.0.2 ещё не подписан и не опубликован; магазинные версии остаются 1.0.1.
Это руководство описывает 1.0.2; для опубликованной 1.0.1 есть
[отдельная редакция](USER_GUIDE_1_0.md).
Сведения о доступности в магазинах:
[Скачать доступную версию](INSTALLATION.md). Для подписанного Firefox 0.0.4.0
есть [отдельное руководство](USER_GUIDE.md).

## Начать работу

Расширение управляет маршрутами браузера. Прокси и локальные службы нужно
настроить и запустить отдельно.

1. Откройте настройки расширения и выберите источник правил.
2. Для работы без автоматической базы выберите **Только мои правила и подключения**.
   В этом режиме при стандартных параметрах сайты идут напрямую, кроме ваших
   правил и маршрутов `.onion`.
3. При необходимости настройте собственное подключение. Для явного режима
   **Прокси** должно быть выбрано хотя бы одно подходящее подключение.
4. Нажмите **Сохранить настройки**, затем **Применить**.
5. Дождитесь состояния **Защита включена**. Оно означает управление
   маршрутизацией, а не проверку доступности всех сайтов и прокси.

В Firefox доступны Anticensority, Antifilter и ручной режим. Автоматическим
прокси-маршрутам Anticensority нужна подходящая локальная служба. Произвольные
PAC-источники поддерживаются только в Chromium. Antifilter в обоих браузерах
использует отдельно настроенные подключения.

## Если сайт открывается не полностью

1. Откройте панель расширения на проблемном сайте и нажмите **Ресурсы сайта**.
2. Нажмите **Начать сбор**, затем **Перезагрузить исходную вкладку**.
   Вернитесь к сайту и повторите действие, которое не работает.
3. Нажмите **Остановить и посмотреть**. Ошибка запроса не доказывает блокировку;
   не выбирайте рекламу и аналитику, если они не нужны.
4. Выберите нужные домены и нажмите **Сохранить выбранные правила**. Для этого
   должно быть настроено подключение для режима **Прокси**. Существующие правила
   **Напрямую** не переписываются.
5. Откройте настройки, проверьте все ожидающие изменения и нажмите **Применить**.

Правила относятся к точным доменам и действуют во всём браузере, включая другие
сайты, использующие те же ресурсы. Сбор работает только для одной обычной вкладки,
до двух минут; приватные вкладки исключены. Результат остаётся в памяти открытого
инструмента и удаляется при очистке, закрытии, переходе на другой сайт или через
десять минут от начала. Выбранные и сохранённые правила остаются в настройках.

## Подключить список Antifilter

Antifilter — дополнительный список сайтов, а не VPN или прокси-сервис.
Он не включает IP-маршруты и не меняет настройки других приложений.

1. Откройте **Источник правил** и выберите **Antifilter**.
2. Разрешите использовать для сайтов из списка подключения, выбранные для
   правил **Прокси**. Подключите собственный прокси, Tor, Tor Browser или WARP
   и включите подходящее подключение для этой области.
3. В Firefox сначала нажмите **Загрузить список Antifilter** и дождитесь
   завершения. Загрузка подготавливает данные, но не включает маршрутизацию.
4. Нажмите **Сохранить настройки**, затем **Применить**.

Список сопоставляет точные имена сайтов: запись домена не добавляет все его
поддомены автоматически. Явное правило **Напрямую** сохраняет приоритет.
Для переноса настроек Antifilter в новый профиль Firefox сначала подготовьте
список; импорт сам не загружает данные и не включает маршрутизацию.

## Выбрать маршрут сайта

Откройте обычный сайт и нажмите значок расширения.

| Режим | Результат |
| --- | --- |
| **Авто** | Снимает применимые явные правила; дальше действуют выбранный источник и общие настройки |
| **Прокси** | Использует подключения, выбранные для явных правил Прокси |
| **Напрямую** | Обходит прокси этого расширения для выбранного сайта |

Можно выбрать только текущий хост или домен вместе с поддоменами. Например,
`example.com` — один хост, а `*.example.com` — домен и его поддомены.
Явное **Напрямую** имеет приоритет над явным **Прокси**.
Внутренние страницы браузера не являются обычными сайтами для этих правил.

Выбор в панели вступает в силу после **Применить**. Если есть другие сохранённые,
но неприменённые настройки, панель предложит просмотреть их или явно применить
все вместе. Закрытие панели без применения не активирует новый выбор.

## Сохранить и применить

**Сохранить** записывает настройки. **Применить** делает проверенные сохранённые
значения действующими. Импорт тоже только сохраняет настройки.

Настройки можно редактировать при включённой защите. До применения продолжают
действовать прежние правила и учётные данные. Надпись **Изменения не применены**
означает, что сохранённые и действующие настройки различаются.

Перед применением сохраните или отмените правки формы. При конфликте с другим
окном проверьте значения заново. После ошибки применения ориентируйтесь на
показанное состояние: сообщение об ошибке не доказывает, что защита выключилась.
Открытые соединения и кэш авторизации браузера могут пережить применение.

## Подключения, Tor и WARP

Для собственных прокси задайте тип, адрес и порт. Логин и пароль указывайте
только при необходимости. Сохранённый пароль не показывается обратно в форме;
неизменённая скрытая запись сохраняет прежнее значение.

У Tor и Tor Browser отдельно выбирается участие в правилах **Прокси**,
маршрутах `.onion` и замене Direct. В новой установке включено только onion:
локальный Tor `localhost:9050`, затем Tor Browser `localhost:9150`.
Для использования в явном Прокси выберите соответствующую область отдельно.

У WARP независимо выбираются правила **Прокси** и замена Direct; эти области
действуют на весь список WARP-подключений. В Chromium общий переключатель
подключения тоже должен быть включён. Быстрые переключатели Прокси сохраняют
уже действующие другие области, но не включают скрыто выключенные настройки.

Замена Direct и запрет Direct по умолчанию выключены. Меняйте их осознанно:
они влияют на маршруты, которым обычно разрешено прямое соединение.
Явное правило **Напрямую** сохраняет свой приоритет.

## Разрешения Firefox

Для используемой общей настройки прокси Firefox требует доступ к приватным
окнам, даже если вы работаете в обычном окне.

1. Откройте **Дополнения и темы → Расширения**.
2. Выберите расширение и разрешите работу в приватных окнах.
3. Вернитесь в настройки расширения, нажмите **Проверить снова**, затем явно
   примените настройки.

Проверка разрешения сама не включает защиту. Доступ к ограниченным сайтам
Firefox — отдельное разрешение, не обязательный шаг включения.
Если управление забрала другая программа, политика или расширение, устраните
показанную причину; повторное сохранение правил само её не исправит.

## Обновить данные маршрутизации

Данные маршрутизации и код расширения обновляются отдельно. Свежая база
не гарантирует доступность настроенного подключения.

Нажмите **Проверить обновления** в панели расширения. Дождитесь результата:
данные не изменились, обновление применено, подготовлено на потом или не удалось.
Если обновление подготовлено, проверьте состояние в настройках: смена источника,
ожидающие настройки или отсутствие управления могут отложить установку.
Повторное нажатие во время проверки недоступно.

В панели отдельно показаны дата исходных данных и время последней успешной
проверки. Успешная проверка не делает старую базу свежей. Неизвестная дата или
данные старше 30 дней сопровождаются предупреждением; оно само не отключает
маршрутизацию и не удаляет рабочую базу.

При включённой маршрутизации обновляется действующий источник с действующими
настройками. Сохранённые, но неприменённые правки остаются отложенными.
При выключенной маршрутизации проверка не включает её. После ошибки сохраняются
проверенные рабочие данные. Обновление базы не заменяет **Применить** для настроек.

Обновление также доступно в настройках. Firefox проверяет источник автоматически
каждые 12 часов. В ручном режиме кнопка панели недоступна; при этом фоновые
проверки Anticensority в Firefox продолжаются и сами не переключают источник.
Источники Chromium также имеют автоматические проверки и повторные попытки.

Firefox обрабатывает Anticensority и Antifilter как данные, без исполнения
скачанного JavaScript. Оба браузера принимают Antifilter только с закреплённого
HTTPS-адреса после проверки формата, размера, даты и целостности. Эти проверки
не подтверждают криптографическую подпись автора списка.

## Перенести настройки

В разделе **Импорт / Экспорт**:

1. Экспортируйте сохранённые настройки из исходной установки.
2. Выберите JSON-файл в другой установке и изучите предварительный просмотр.
3. Проверьте неподдерживаемые поля и недостающие учётные данные.
4. Подтвердите сохранение импортированных настроек.
5. При необходимости введите учётные данные, сохраните и отдельно примените.

Импорт заменяет сохранённые настройки, не объединяет их с прежними и не включает
защиту. Это ручной перенос, не облачная синхронизация и не полный резервный снимок.

Экспорт не включает пароли, логины и адреса пользовательских источников.
Правила сайтов и адреса прокси остаются в файле: храните его приватно.
Возможности браузеров отличаются — предупреждения при импорте нужно проверить.

## Если возникла проблема

Проверьте состояние в **Обзоре** и **Обслуживании**. Следуйте
[инструкции помощи](../../SUPPORT.md): там собраны быстрые проверки и форма
обращения. При необходимости приложите отдельный **Экспорт для поддержки**,
предварительно просмотрев его. Файл переноса настроек для этого не подходит.

## English summary

Version 1.0.2 separates **Save settings** from **Apply**. Auto follows your source
and rules; Proxy requires suitable selected connections; Direct bypasses this
extension's proxy routing. The extension provides no VPN or proxy service.
Imports save settings without activating them. Updates preserve applied settings
and keep inactive routing inactive. Antifilter is an optional exact-host list
for separately configured connections. The popup shows source date and last
successful check separately. Chromium 1.0.2 is available as a manual ZIP; Firefox 1.0.2 is not yet signed or published.
These additions are not part of the current 1.0.1 store versions;
use the [installation page](INSTALLATION.md) for store links and manual downloads.
